# KSODI-Light User Feedback

This folder contains bounded examples of user feedback about KSODI-Light
prompt use.

Begin with the
[KSODI-Light Prompt Feedback Example v3.51](./KSODI-Light-Prompt-Feedback-Example_V351.md).
It shows how an attributable observation from use may be recorded without
turning one report into validation, a universal result or a method change.

For the current Light method and copy-and-paste guidance, return to the
[KSODI-Light README](../README.md) and the
[Agent Skills hub](../agent-guidance/README.md).

Feedback material is evidence for later review. It does not by itself alter a
versioned KSODI definition, establish longitudinal effect or authorize formal
Observer and Controller claims.
