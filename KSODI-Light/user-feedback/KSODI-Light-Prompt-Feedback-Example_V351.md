# KSODI-Light Prompt Feedback Example v3.51

Status: `V351_PUBLISHED_ON_PUBLIC_MAIN / COPY_AND_PASTE_FEEDBACK_EXAMPLE /
NOT_FORMAL_OBSERVER`

This example is for users who want short, understandable feedback on a
request, an assistant answer or the visible working frame of the current
interaction. It supports clarification and task fit; it does not judge a
person, certify truth or perform a formal KSODI measurement.

## Copy-and-paste prompt

```text
Use KSODI-Light as a reflective working agreement for this interaction.

Please review my request, your answer or the visible working frame with five
questions before continuing:

K — Is enough context visible for this task?
S — Is the contribution structured so that it can be followed or used?
O — Are important claims, objects and references grounded enough?
D — Is the intended distinction sufficiently clear?
I — Is enough relevant information or a useful new impulse present?

Do not routinely output scores. If something important appears incomplete,
briefly explain what is missing, why it matters and one concrete way to improve
the request, answer or visible working frame. Ask one focused clarification
question when that is more helpful than continuing with assumptions.

Do not diagnose or grade me. Keep observations, inferences and proposals
distinguishable.
```

## Optional estimate request

If a numeric orientation would help, add:

```text
Please also show your rough task-specific completeness estimate for each
relevant K/S/O/D/I dimension on a 0–5 scale.

Use 0 when the visible material is not yet usable for that part of the task
and 5 when the task-relevant elements appear sufficiently complete for the
requested processing. Label every value as an approximate estimate and
explain its visible basis. Do not calculate a single total score.
```

The values remain optional and secondary to the explanation. A low estimate
does not mean that a person or contribution is generally poor; it identifies
visible material that may not yet support the declared task.

## Boundary to formal KSODI

This example does not calculate formal Layer-1 operator values in `[0,1]`, a
complete typed `Z`, `IK`, `R0`, `IK_rel` or R-family views. It does not create
an external Observer or authorize hidden evaluation, escalation or action.

Repeated use may affect later visible interaction only under additional
platform, context and reinjection conditions. Prompt presence does not prove
persistent learning, memory, internal-state change or a causal long-term
effect.

Pause or reset the working agreement whenever it no longer helps the task.
