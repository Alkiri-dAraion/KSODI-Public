## Public orientation note

This folder contains the Public-`main` KSODI Standard-Eval materials for
structured monadic observation, implementation-oriented review, discussion
and version traceability. Public `main` currently contains selected cumulative
v3.51 files; the tagged `v3.5.0` release remains the fixed citation snapshot.

The shared structural and method boundary with KSODI-Full is documented in
the root
[KSODI-Standard-Eval / KSODI-Full Transition V350](../KSODI-Standard-Eval_Full-Transition_V350.md).

The public 3.3 files and the later v3.42 working / implementation line are

on Public `main` by the current v3.51 line.

## Role of Standard-Eval

KSODI Standard-Eval is the structured monadic observation and evaluation
branch of the KSODI Method. It retains numeric results together with typed
nonnumeric statuses, identities, profiles, evidence and provenance so that
derived views remain explainable and reconstructible.

Standard-Eval focuses on:

- the five KSODI operator families;
- complete typed state-vector observation;
- monadic IK readings and reconstructible joint views;
- source-local movement, window and comparison diagnostics.

In the current v3.51 direction, monadic interaction coherence is not
relational coherence or resonance. The
complete monadic Standard-Eval line is `K/S/O/D/I -> Z -> IK`; Standard-Eval
ends with `IK`.

After `Z`, the architecture branches. `R0 / R_0` belongs to KSODI-Full gate
logic and is evaluated from distinguishable `Z`-trajectories in parallel to
monadic `IK`. Current dyadic `IK_rel` requires an explicit dyadic pairing and
an open numeric canonical complete `R0` gate under the exact required profile;
an n-adic R0 result does not open it. `R0`, `IK_rel` and the further R-family
are not part of Standard-Eval.

## Current research direction

The current method line distinguishes monadic observation layers from dyadic
and n-adic relational observation layers.

This distinction matters for agentic systems: a human-machine, agent-agent or
n-agent interaction may look active or even resonant while still lacking
observable direction, comparability or stable interaction coherence.

Public files in this folder should therefore be read as public method
documentation for the released monadic Standard-Eval line, not as a complete
software implementation or empirical validation claim.

Relational observation and its gates belong to KSODI-Full. Controlled
intervention, policy-defined responses and action authority remain in a
separately authorized Controller/action space outside both current Observer
method scopes.
