# Layer 3 — KSODI Monadic Interaction Coherence (`IK`)

`IK` is one source-attributed scalar projection of complete canonical Z onto
one named and versioned monadic coherence axis. It is not resonance, relation,
truth, utility or a sixth coordinate.

Reader order:

1. read the method for the semantic and mathematical contract;
2. read the companion only for conditional implementation guidance;
3. return to typed Z whenever a coordinate is non-numeric;
4. consult `R0` and `IK_rel` separately only when the question itself becomes
   relational; they are not continuation steps of the IK calculation.

Core boundary:

```text
complete canonical Z -> canonical IK
fixed explicit partial Z^[M] -> named reduced IK^[M]
changing or hidden M -> no comparable IK dynamic or window
typed distinguishable Z trajectories -> separate R0 relational branch
IK never opens, feeds or replaces R0
current dyadic IK_rel -> explicit dyadic pairing plus open numeric canonical
                         complete dyadic R0 under the exact required profile
```
