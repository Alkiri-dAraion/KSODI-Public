# Layer 3 — KSODI Monadic Interaction Coherence (`IK`)

Layer 3 derives several jointly inspectable monadic readings from one complete,
source-attributed, typed Z state. It does not add a sixth Layer-1 coordinate and
does not replace the labelled Z object.

The v3.51 family contains:

```text
complete typed Z
├── IK_w             weighted-axis position
├── IK_M2            normalized complete-vector magnitude
├── IK_ref           fixed-reference-axis position
├── AxisDev_ref      deviation from the fixed reference diagonal
└── identities, profiles, statuses and provenance
```

The jointly navigable human term is `IK-Gesamtbild`; its technical view ID is
`ik_joint_evaluation_view`. It is a view, not a total score or replacement
truth.

## Reader route

1. Read the method for meanings, formulas, identities, comparison and windows.
2. Read the companion for conditional records, pseudocode, migration and tests.
3. Return to complete typed Z whenever a component is non-numeric or a scalar
   hides a relevant coordinate difference.
4. Treat R0 and IK_rel as separate relational branches with their own gates;
   neither is a continuation step computed from IK.

## Three reading channels

- The purpose-required machine object retains complete typed Z, raw component
  results, identities, profiles, numeric policy, windows and provenance.
- An assistive LLM may interpret a governed projection but does not create a
  new IK result, fill missing evidence or infer hidden state.
- A human/governance view may round and simplify, but must disclose its policy
  and preserve the permitted route back to the richer record.

Raw mathematical result, numeric policy, display value and interpretation are
different objects.

## Core boundary

```text
complete canonical Z -> IK_w + IK_M2 + IK_ref + AxisDev_ref
fixed explicit partial Z^[M] -> named reduced IK_w^[M] only
changing or hidden M -> no comparable reduced dynamic or window
typed distinguishable Z trajectories -> separate R0 relational branch
IK never opens, feeds or replaces R0
```

No IK component, joint view, ranking, corridor, dynamic, alert or Hangar view
authorizes steering or intervention. Any action requires separately governed
human or Controller authority.

Independent runtime conformance remains outstanding and is not supplied by
the reference mathematics alone. A software change, implementation merge,
tag, GitHub Release, DOI or Zenodo artifact remains a separate action.
