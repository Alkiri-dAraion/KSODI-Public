# Historical Document Snapshots

This directory preserves superseded public document states for provenance and
review. The snapshots retain their historical wording and may contain links
that were root-relative in their original locations.

Do not use these snapshots as current navigation, release or method guidance.
Use the active documents in the repository root and current method folders.

Durable archive paths identify the archived object semantically through its
scope, source version and predecessor/successor relation. They do not expose
an internal review, move or disposition date merely because repository work
occurred on that day. Git history and recorded commit/blob/hash identities
retain that processing provenance. Dates remain visible when they are intrinsic
to the historical object, publication, release, source snapshot or timeline.
