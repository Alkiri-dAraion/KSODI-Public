# Layer 5 - IK_rel

Status: public v3.50 reference release

`IK_rel` is the relational coherence projection after a stable `R0` gate. In
v3.50 it is formally released for the dyadic case. It belongs inside the
relational branch, not in the monadic `IK` branch.

Released method file:

- [`KSODI_Dyadic-Relational-Coherence-IK_rel_V350.md`](./KSODI_Dyadic-Relational-Coherence-IK_rel_V350.md)

Potential views include `Delta IK_rel`, `Delta2 IK_rel`, `IK_relSigma` and
`IK_relSigma(Hangar)`, where the use case requires them.

`IK_rel` measures compatibility of coherence movements, not agreement,
alignment, coupling or resonance. `R_geom`, `R_pace` and later R-family layers
remain staged unless their own release status says otherwise.
