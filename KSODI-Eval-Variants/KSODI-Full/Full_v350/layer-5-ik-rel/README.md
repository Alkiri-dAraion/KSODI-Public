# Layer 5 - IK_rel

Status: public placeholder, pending private v350 review

`IK_rel` is the dyadic or n-adic relational coherence projection after a
stable `R0` gate. It belongs inside the relational branch, not in the monadic
`IK` branch.

Potential views include `Delta IK_rel`, `Delta2 IK_rel`, `IK_relSigma` and `IK_relSigma(Hangar)`, where the use case requires them.
