# KSODI Standard-Eval Operators v350

Status: public preview, released operator-by-operator after private review

This folder contains the public v350 Standard-Eval operator line as it is released from the private workbench.

The v350 line supersedes the earlier public v3.3 placeholders and drafts as current method orientation. Older folders remain available for provenance and version traceability, but they should not be used as implementation guidance unless a file explicitly says so.

Current released operators:

- [`operator-I_v350.md`](./operator-I_v350.md) - `I0`, Observable Information Impulse

## Boundary

The v350 operator files use observer-facing names:

- `K0` - Observable Context Completeness
- `S0` - Observable Structural Coherence
- `O0` - Observable Grounded Objectivity
- `D0` - Observable Clarity
- `I0` - Observable Information Impulse

KSODI-Light may still use shorter human-facing labels for reflection and prompt work. The difference is a layer and viewpoint distinction, not a competing definition.
