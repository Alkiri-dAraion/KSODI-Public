# Layer 2 - State Vector Z

Status: public v350 reference release

Layer 2 represents the KSODI state vector over the operator values:

```text
Z(t) = (K0, S0, O0, D0, I0)
```

Potential views include `Delta Z`, `Delta2 Z`, `ZSigma` and `ZSigma(Hangar)`, where the use case requires them.

Released file:

- [`Z_Vektor.md`](./Z_Vektor.md) - KSODI State Vector Z, released together with public `K0`

Hangar views are mentioned as optional state-space views. Detailed Hangar
method notes are maintained separately and should only be linked where released
for the relevant public scope.
