# KSODI v3.51 Implementation-Transfer Examples

This folder keeps bounded public documentation examples showing how the
moving-Public KSODI v3.51 method can be mapped into a concrete observable
setting. It contains no executable reference implementation and establishes no
runtime-conformance claim.

Before using any example, read the root
[KSODI Implementation Guardrails](../IMPLEMENTATION_GUARDRAILS_V351.md). Every
example must preserve source-attributed evaluation units, local monadic
trajectory order, explicit relational pairing and the boundary between
individual operators and complete KSODI projections.

These examples and notes are intentionally separate from:

- canonical Standard-Eval definitions
- canonical / structural KSODI-Full definitions
- private customer or PoC implementation work

Available examples:

- [Human–chatbot Observer example v3.51](./chatbot-human-observer_V351/README.md)
- [Trajectory-boundary notes](./trajectory-boundary-notes/README.md)

This small directory is not a delivery roadmap or a promise of additional
examples. New examples enter only after their method version, evidence,
privacy boundary and reader value have been reviewed.
